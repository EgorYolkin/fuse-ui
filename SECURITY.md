# Security Policy

## Supported versions

Security fixes are provided for the latest published version of `@egoryolkin/fuse-ui`. Upgrade to the latest release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue, discussion, or pull request.

Use [GitHub's private vulnerability reporting](https://github.com/EgorYolkin/fuse-ui/security/advisories/new) to send a confidential report. Include, when possible:

- the affected package version and component;
- impact and attack scenario;
- reproduction steps or a minimal proof of concept;
- suggested remediation;
- whether the issue has been disclosed elsewhere.

You should receive an acknowledgement within 7 days. The maintainer will investigate, coordinate a fix and release, and credit the reporter if requested. Please allow reasonable time for remediation before public disclosure.

## Scope

Security reports are appropriate for vulnerabilities in the package or its release process. General bugs, accessibility problems, and feature requests should use the public issue templates.
